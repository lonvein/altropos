# altropos

Прототип навигатора сотрудника по внутренним регламентам МФТИ: гибридный поиск, локальная языковая модель и ответы с проверяемыми источниками.

## Команда и задачи

| Участник | Ответственность | Задание |
|---|---|---|
| Клим, капитан | RAG, модели, общие контракты и интеграция | [Клим.md](Клим.md) |
| Егор | Документы, очередь обработки, редакции и импорт сайта | [Егор.md](Егор.md) |
| Глеб | Веб-интерфейс, Docker, проверка запуска и демонстрация | [Глеб.md](Глеб.md) |

Основное оборудование — A100; резерв — RTX 3060 Ti с 8 ГБ VRAM. Конкретные профили и точки стыковки закреплены в заданиях.

Каждый участник работает в своей ветке и передаёт изменения через pull request. Клим проверяет совместимость и сливает в `main`. Изменение общего API сначала согласуется всей командой.

В репозитории пока опубликованы организационные файлы; готовность приложения и инструкция запуска появятся после реализации. Внутренние документы, веса моделей, локальная база и секреты не включаются в Git автоматически.

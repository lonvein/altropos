# Чек-лист интерфейса

Статус на 2026-11-12: **не выполнялось**. В рабочем дереве нет `navigator/main.py`,
шаблонов, Compose и подключённых routers; запускать интерфейс не на чем.
Таблица ниже — обязательный протокол для стенда, а не отчёт о проверке.
Результат `PASS` ставится только после реального прогона с настоящими API.

## Условия

- Зафиксировать коммит, профиль (`a100`/`3060ti`/`4b`), ревизии весов, браузер.
- Использовать чистый `DATA_DIR` и только разрешённые документы.
- Для проверки `unavailable` отключить LLM и ML по отдельности; не менять код.
- Сохранять скриншоты и JSON ответов в `artifacts/ui/<date>/`.
- Для каждого пункта: `PASS`, `FAIL` (с описанием) или `NOT_RUN`.

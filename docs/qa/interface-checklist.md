# Чек-лист интерфейса

Статус на 2026-11-12: **протокол для A100 и 3060 Ti не выполнялся**. Веб-оболочка,
шаблоны и Compose в дереве есть, но реальные routers RAG/ingestion, веса и GPU
недоступны. Оболочка проверена отдельно на `development` с явно помеченной
синтетической заглушкой; это не прогон модели. В таблицах ниже столбцы A100 и
3060 Ti остаются `не выполнялось`, пока проверка не пройдена на стендах.

## Что проверено на оболочке

Проверка от 2026-11-12: локальный запуск без Docker, `PROFILE=development`,
`UI_SYNTHETIC_FALLBACK=true`. Все ответы API содержат `ДЕМО-ЗАГЛУШКА`.

| Проверка | Результат | Что именно подтверждено |
|---|---|---|
| `/`, `/documents`, `/health` | PASS | страницы и health отдают 200; CSP и защитные заголовки |
| Шесть статусов `/api/ask` | PASS | `answered`, `partial`, `not_found`, `ambiguous`, `conflict`, `unavailable` возвращаются с предупреждением |
| Ссылки `sources[].url` | PASS | `/api/sources/<fragment_id>` отдаёт 200 и HTML |
| Повторный GET источника | PASS | ответ не меняется; это эмуляция F5, не проверка браузера |
| Загрузка `queued → processing → ready` | PASS | задание и документ меняют состояние |
| `needs_review` и `error` | PASS | статусы и причины видны в API; в поиск не попадают |
| Дубликат SHA-256 | PASS | возвращается тот же `document_id`, `duplicate=true` |
| Экранирование названия | PASS | `<script>` в названии не исполняется, выводится как текст |
| Отключённые модели | PASS | `/health` показывает `limited` и причины |

Не проверено на оболочке: исполнение JavaScript в реальном браузере, кнопка
«Назад», тайм-аут и отказ настоящей модели, переход к странице PDF, импорт
реального сайта, перезапуск и перенос `DATA_DIR`. Для этих пунктов нужен стенд.

## Условия

- Зафиксировать коммит, профиль (`a100`/`3060ti`/`4b`), ревизии весов, браузер.
- Использовать чистый `DATA_DIR` и только разрешённые документы.
- Для проверки `unavailable` отключить LLM и ML по отдельности; не менять код.
- Сохранять скриншоты и JSON ответов в `artifacts/ui/<date>/`.
- Для каждого пункта: `PASS`, `FAIL` (с описанием) или `NOT_RUN`.

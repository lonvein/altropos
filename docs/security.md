# Секреты и гигиена репозитория

Проверка от 2026-11-12: **секретов и внутренних файлов не найдено**. Удалять
ничего не пришлось: `.env` в рабочем дереве отсутствует, внутренние документы и
веса не отслеживаются Git.

## Что проверено

```bash
./scripts/check_hygiene.sh
```

| Проверка | Результат |
|---|---|
| Отслеживаемые `.env`, ключи, SQLite, GGUF, PDF/DOCX/XLSX | не найдены |
| Приватные ключи и типовые токены (`sk-`, `ghp_`, `AKIA`) | не найдены |
| Присваивания вида `password=`, `api_key=`, `secret=` | не найдены |
| Абсолютные домашние пути | не найдены |
| Искусственный корпус помечен | да, каждый документ и фрагмент |

Скрипт — минимальная страховка, а не полноценный сканер секретов. Перед публикацией
дополнительно просмотреть diff и историю выбранных файлов.

## Правила

- `.env`, `.env.*` (кроме примеров), токены, пароли и ключи не коммитить.
- Веса, базы, индексы, оригиналы и производные документы не коммитить.
- Внутренние документы и персональные данные не добавлять даже в тесты.
- Для тестов и демонстрации — только `tests/fixtures/synthetic_corpus.json`
  с явной пометкой «ИСКУССТВЕННЫЙ ПРИМЕР».
- Секреты передавать отдельно от Git; в README и `.env.example` — только имена
  переменных и безопасные значения по умолчанию.

## Команды

```bash
git status --short
git ls-files | grep -E '(^|/)(\.env$|Данные/|.*\.(pem|key|sqlite|gguf|pdf|docx|xlsx)$)' || true
./scripts/check_hygiene.sh
```

Если проверка падает, файл не коммитится до устранения причины.

# Требования из консультации

Источник: предоставленная пользователем сжатая консультация `new_convercation.txt`.
Это дополнительные пожелания заказчика, а не независимая сверка исходного конкурсного ТЗ.
Рекомендации конкретных библиотек и моделей в конце консультации не являются обязательным стеком.

| Требование | Проверяемая задача и критерий приёмки |
|---|---|
| Рабочий веб-интерфейс или бот | Заказчик самостоятельно задаёт вопрос, получает ответ и открывает основания; ссылка на GitHub не заменяет демо |
| Ответы по документам МФТИ | Каждое утверждение подтверждено дословной цитатой; при нехватке данных явный отказ или неполный ответ |
| Загрузка PDF/DOCX администратором | Файл проходит обработку и необходимую проверку, после публикации доступен поиску; ошибки видны |
| Разделение пользователя и администратора | Публичный читатель задаёт вопросы; загрузка и изменение базы доступны только в закрытом контуре |
| Дополнение базы с сайта МФТИ | Ограниченный импорт внешних регламентов с проверкой адресов и перенаправлений; импорт не обходит review |
| Неоднозначные вопросы | Уточняющий вопрос или понятные варианты вместо длинного неподтверждённого ответа |
| Ответ за 1–2 минуты | Измерить полное время через публичный интерфейс, включая поиск и проверку; по одному вопросу SLA не подтверждать |
| Перспективный объём 600–700 документов | Отдельное испытание производительности и памяти на разрешённых данных; текущие 15 документов не доказывают масштабируемость |
| Набор 15 + 5 | Сохранить одобренные 15; пять отложенных файлов загружать штатным ручным сценарием |
| Личный документ и вопрос по нему | Уточнить область видимости и срок хранения; документ одного пользователя не должен попадать другому. Не считать общую административную загрузку реализацией личного пространства |

Ближайший порядок: исправить полный просмотр и воспроизведённые дефекты поиска;
проверить совместимость импорта и ролей; проверить пять ручных загрузок;
измерить качество и задержки; отдельно спроектировать изоляцию личных документов
и испытать целевой объём. Связанный подробный план: [next-steps.md](next-steps.md).

## Назначение метаданных

Кнопка «Метаданные» открывает структурированную карточку: название, номер,
дата издания, период действия, проверка и связи редакций (`MetadataPatch`
в `navigator/schemas.py`). Это не расшифровка документа.
Извлечённый/OCR-текст хранится в канонических блоках и опубликованных фрагментах;
он показывается в HTML-просмотре. Неизменяемый исходный файл открывается отдельно.
Одобрение OCR не подтверждает юридическую актуальность и не должно автоматически
устанавливать `reviewed=true`.

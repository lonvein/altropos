
=======
Клим, вот выжимка из диалога с заказчиком. Я убрал «воду» и оставил только технические требования и бизнес-логику, которые критичны для твоего решения.

### 1. Формат сдачи и тестирования
*   **Интерфейс:** Заказчику нужен готовый UI (чат-бот или веб-интерфейс), чтобы он мог лично задать вопросы. GitHub-репозитория ему недостаточно.
*   **Демо:** Решение должно быть развернуто так, чтобы можно было «покидать» документы и получить ответ в реальном времени.

### 2. Ключевые функциональные требования
*   **RAG (Поиск по базе):** Ответы строго по документации МФТИ. **Галлюцинации недопустимы.**
*   **Админка для документов:**
    *   Возможность загружать новые файлы (PDF/Docx) через интерфейс.
    *   Разделение ролей: «Пользователь» (задает вопросы) и «Админ» (загружает базу знаний).
*   **Внешние источники:** Парсинг сайта МФТИ для регламентов, которых нет во внутреннем хранилище.
*   **Обработка неоднозначных запросов:** Если вопрос размыт, бот должен просить уточнения или предлагать варианты, а не выдавать «простыню» текста.

### 3. Производительность (SLA)
*   **Время ответа:** Максимум **1–2 минуты**. Если дольше — пользователь сам прочитает документ.
*   **Инференс:** Заказчик планирует использовать вычислительные мощности МФТИ, но организаторы рекомендуют закладываться на стандартные условия (равные для всех), чтобы не зависеть от внешней инфраструктуры.

### 4. Данные
*   **Объем:** ~600–700 регламентов в перспективе.
*   **Тестовый сет:** 15 документов для обучения/индексации, 5 для теста загрузки.
*   **Кастомизация:** Пользователь хочет иметь возможность загрузить свой личный документ и сразу спросить по нему.

### Твой план действий (как ML-специалиста):
1.  **Архитектура:** FastAPI/Streamlit для UI + LangChain/LlamaIndex для оркестрации.
2.  **Модель:** Локальная LLM (например, Qwen2.5-7B или Llama-3-8B) с квантованием под 8GB VRAM (твоя 3060 Ti).
3.  **Векторная БД:** ChromaDB или FAISS (легко деплоится в Docker).
4.  **Оптимизация:** Используй GPU-ускорение для эмбеддингов и инференса, чтобы уложиться в 1–2 минуты.
